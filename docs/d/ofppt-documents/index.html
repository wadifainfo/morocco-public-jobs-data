OFPPT course documents catalogue (Morocco vocational training)

A catalogue of 739 course documents used in Morocco's public vocational-training system (OFPPT): 548 courses, 152 end-of-module exams (EFM), 25 exercise sets and 14 practical-work sheets, across 25 tracks (networks and IT, business management, administrative assistant, electricity, and more).

Each row gives the title, module, type, track and a link to the document page on Wadifa Info, where it can be previewed and downloaded as PDF.

field description
id document id
title, module document title and module
type cours / efm / exercices / tp
track, track_code, tracks OFPPT track(s) the document belongs to
size_kb PDF size
page_url document page (preview, download)
pdf_url direct PDF link

About the documents

The documents circulate among OFPPT trainees and are not published openly by the Office. Wadifa Info re-hosts them as PDFs after a safety check (no scripts or embedded files). This catalogue lists metadata only. To report a document or request its removal: https://www.wadifa-info.com/ofppt-docs/signaler
