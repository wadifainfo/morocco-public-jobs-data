# Morocco public-service recruitment notices, August 2024 – September 2026

One row per concours (recruitment exam) announced on the official public-jobs portal emploi-public.ma between 1 August 2024 and 30 September 2026, as collected by Wadifa Info.

- **Rows:** 8,223 concours, 103,089 posts
- **One row per concours:** later convocation, oral and result notices published under the same link are not counted again.
- **No personal data:** notices only (employer, grade, posts, place, dates, required diplomas). No candidate lists.
- **Licence:** CC BY 4.0. Please cite: "Morocco public-service recruitment notices 2024-2026, Wadifa Info, https://www.wadifa-info.com/fr/qui-recrute-fonction-publique-maroc"

## Columns
| Column | Meaning |
|---|---|
| `id` | Wadifa Info notice id (the page is `url`) |
| `published` | Date the notice appeared on emploi-public.ma (YYYY-MM-DD) |
| `deadline` | Application deadline, empty if not given |
| `exam_date` | Exam date announced in the notice, empty if not given |
| `employer_type` | `administration_etat`, `etablissement_public` or `collectivite_territoriale` |
| `employer_fr`, `employer_ar` | Employer name as published |
| `grade_fr`, `grade_ar` | Grade (post) opened |
| `posts` | Number of posts |
| `region_fr`, `city_fr` | Place of work when the notice gives one |
| `diplomas_fr`, `specialties_fr` | Required diplomas and specialties, as published |
| `recruitment_type_fr` | Concours, test, selection on file… |
| `url` | Notice page with the link to the official announcement |

## Findings from this table
See the study [Qui recrute dans la fonction publique ?](https://www.wadifa-info.com/fr/qui-recrute-fonction-publique-maroc): State administrations run 14% of concours but offer 66% of posts; the median application window is 16 days (the legal minimum is 15, décret 2-11-621 art. 4).

## Limits
- Coverage starts in August 2024. For yearly totals since 2012, use the official data.gov.ma series summarised in `data/studies`.
- Diplomas and specialties are free text from the notices.
