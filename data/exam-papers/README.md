# Index of Moroccan public-sector exam papers

An index of **2,585 past exam papers** (مباريات / concours) for jobs in the Moroccan public sector and for entrance to public schools, years 1988–2026. **1,085 of them have a worked correction.** Each row points to the paper's page (Arabic and French), where the PDF can be viewed.

| Column | Meaning |
|---|---|
| `id` | Paper id on Wadifa Info |
| `title_ar`, `title_fr` | Title |
| `employer_ar`, `employer_fr` | Ministry or body that set the exam (empty when unknown) |
| `grade_fr`, `specialty_fr` | Grade and specialty when known |
| `year` | Exam year |
| `has_correction` | 1 if the page has a worked correction |
| `url_ar`, `url_fr` | Paper page |

- This is an **index only**: no paper text is included. The papers were set by the public bodies named in each row; most come from official websites, emploi-public.ma and the Concours National Commun (CNC).
- **Browse by exam family:** https://www.wadifa-info.com/fr/modeles-concours (Arabic: https://www.wadifa-info.com/نماذج-مباريات)
