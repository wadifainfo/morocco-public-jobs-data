# Moroccan embassies and consulates abroad — 161 posts

Every diplomatic and consular post of the Kingdom of Morocco listed in the Foreign Affairs ministry's official directory: **102 embassies, 55 consulates general** and 4 other missions (liaison office, consular section, representation office, permanent mission), with country (French and Arabic), city, type, official name, address, phone and website when the directory gives one.

| column | description |
|---|---|
| country_fr, country_ar | country |
| city | city of the post |
| type | Ambassade / Consulat général / other |
| name | official name of the post |
| address | address as published |
| phone | phone number(s) as published |
| website | post website (when listed) |

## Source
Copied from the [annuaire of the Ministry of Foreign Affairs, African Cooperation and Moroccans Living Abroad](https://diplomatie.ma/fr/annuaire) as published, consulted on 19 October 2026. Some addresses are incomplete in the source. Check opening hours and the post's consular district with the post itself before travelling. Consular appointments are booked on rdv.consulat.ma.
