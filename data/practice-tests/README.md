# Moroccan school practice tests with corrections (فروض محروسة مع التصحيح)

**138 original practice tests** for Moroccan pupils, from 5th year primary to Tronc commun scientifique, each with a full worked correction, a marking scale and a printable PDF. 81 are in Arabic and 57 in French.

| Level | Tests |
|---|---|
| 5e année primaire (`5ap`) | 12 |
| 6e année primaire (`6ap`) | 18 |
| 1re année collège (`1ac`) | 29 |
| 2e année collège (`2ac`) | 24 |
| 3e année collège (`3ac`) | 32 |
| Tronc commun scientifique (`tc`) | 23 |

| Column | Meaning |
|---|---|
| `slug` | Test id |
| `level`, `level_ar`, `level_fr` | School level |
| `subject`, `subject_ar`, `subject_fr` | Subject |
| `language` | `ar` or `fr` |
| `semester` | 1 or 2 (الدورة) |
| `test_number` | Devoir 1 or 2 of the semester (الفرض) |
| `model` | Model number when a slot has several versions |
| `duration`, `scale` | Time allowed and marking scale |
| `exercises` | Number of exercises |
| `lessons` | Lessons covered, separated by ` \| ` |
| `title` | Title |
| `page_url` | The test online: statement, correction, marking scale |
| `pdf_url` | Printable A4 PDF: statement + correction |

- These are **original tests written by Wadifa Info** against the official Moroccan programmes named on each page. They are not past official exams.
